# raw/

Thư mục này chứa ý tưởng gốc của chủ dự án, chép nguyên văn. Không sửa file nào ở đây; muốn đổi ý thì thêm file mới có ngày.

- Tên file: `YYYY-MM-DD-<chủ-đề-ngắn>.md`, ngày là ngày của tin đầu tiên trong file.
- Mỗi tin giữ nguyên chữ, dưới một dòng `## <ngày giờ>`.
- `DESIGN.md` là bản chép nguyên văn đặc tả thiết kế do chủ dự án viết (bản gốc ở gốc repo).
- Người chơi luôn được ghi là `{{user}}`.
- Danh sách mọi file ở `../index.md`.
